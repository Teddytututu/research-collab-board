# 事件优先心跳

[English](heartbeat.md) · [守夜人接入](../docs/night-watch.md)

守夜人是观察进度、写入可操作事件的普通脚本，常规完成数由它直接更新。助手从需要处理的事件开始思考。

1. **先读 `data/attachments/night-watch/events.json` 中的 `events` 列表。** 自定义数据目录时，采用该目录下相同的相对路径。文件缺省或事件集合为空时，本轮安静结束。事件文件格式损坏或读取失败属于守夜人故障，保留现场并对具体原因提示一次。
2. 出现可操作事件后，只读相关任务、适用的当前指令和最近 **20 条交流**。沿用已接受的配置与原会话，按事件需要补读证据。
3. 完成已授权且可独立推进的恢复或实现。研究设计变更交 Claude，重大资源、账号与发布选择交用户；等待决定时继续独立工作。
4. 记录具体结果，用 `python scripts/night_watch.py --project-root . --ack EVENT_ID` 确认已处理事件；自定义数据目录时附本部署的 `--data-dir`。保留其他事件与新到事件。行动仍在进行时保持事件待处理；同一条件的重复通知合并处理。事件生命周期见[守夜人接口](../docs/night-watch.md)。

## 通知条件

| 事件 | 动作 |
| --- | --- |
| 任务完成 | 收齐最终结果，通知读者关心的成果。 |
| 进程提前退出或进度停滞 | 读取任务证据，在授权内恢复，并说明具体故障或恢复结果。 |
| 合规空闲资源出现且有排队任务 | 按部署额度接续已接受任务，本地更新进度。 |
| 容量触及配置保护线 | 执行容量保护、保留现有产物，并通知需要的具体选择。 |
| 需要研究或用户决定 | 向决定者说明具体选项与建议。 |
| 正常运行、条件保持或常规进度 | 守夜人更新本地进度，本轮安静结束。 |

## 首次安装与调度

按[守夜人接入](../docs/night-watch.md)使用 Windows `schtasks` 注册、macOS/Linux cron 示例、演练与手动接续命令。注册沿用本轮安装授权；注册失败时提供手动命令，其余独立安装步骤继续完成。守夜人注册、看板登录启动、助手原生唤醒分别管理，事件通过本部署已配置的接入转给原助手会话。

检查输出与诊断细节保存为项目本地运行记录，给用户的成果与决定采用[写法规则](writing.zh-CN.md)。
