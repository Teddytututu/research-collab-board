# 研究报告写法

[English](../SKILL.md)

围绕读者的问题组织论证，结构随研究问题与证据安排。作者贡献、数字与论断强度忠实于原材料。技能支持任务授权内的写作与本地准备，外部发布沿用用户选择的流程。

## 一、先想清读者需要什么

明确读者，以及读完应带走的四件事：研究问题、答案、证据与下一步。按这四个问题组织全文，先呈现答案。保留研究者的贡献：观察数据时的直觉、假设为何改变、理论解释；结合实验记录读取作者自己的思考。

新结果改变论证时，重整全文。详细核验、来源、执行记录与逐样本输出放入独立附件，正文聚焦发现和必要科学背景。

## 二、按证据价值取舍

- 留下能亲眼比较的图、计算量与样例；修复历史和逐条记录放入完整结果页或附件。
- 例子带分母，按评测集合中实际占比说明代表性。
- 方法名与实现一致，区分发表方法、复现与改编。相关负结果写清适用范围，其他实验保留在研究归档。
- 让技术内容体现研究价值；任务数、个人工作量与人员安排放入工作记录。
- 成本低且已获授权的补充检查先完成，再确定后续工作。打磨投入与报告后续用途相称。

## 三、严谨

- 比较前核对样本、分辨率、判分与硬件；条件有实质差异时说明影响。
- 基准判分用于论文比较，独立判定用于检验改进主张。适用时采用隐藏方法身份的人工评审或全新上下文的模型，并抽查与人工的一致率。结论强度以现有评测支持范围为准。
- 因果表达配相应实验，假设标明“可能”，原因仍待确定时如实说明。
- 时间比较采用相同硬件与统计范围，GPU、CPU 分开记录。口径会改变结果时给出支持的区间，硬件不同的结果分别展示。
- 存疑样本按评测协议处理，汇总前明确口径；处理方式会影响结论时给出存疑数量与敏感性结果。质量分数与评审一致率分别统计。
- 画风、写实程度等主观指标与客观正确性分开报告。

## 四、研究者口吻

直接写发现、数字、计划怎样调整，采用肯定句与日常语言。标题说明具体内容，例如“计算量与正确数的关系”“各阶段的假设、实验与调整”。保留实质技术内容，工作量写工作记录。

每句话帮助读者理解研究。日期横幅、修改评论与阅读操作提示属于流程信息时放入附件。主要结论采用一句加粗论断，后接两三句证据。必要定义与学术引用遵循所需格式，详细追踪记录另存。

## 五、图表与版式

- 比较类结论先图后精确数字表，小样本组用计数。
- 一张表围绕一个比较，标清复现结果与论文结果，区分计数与分数。
- 同一种方法全文颜色一致，包括流程图、曲线、标注与表格；相近方法采用相近且可分辨的颜色。
- 基线与改后结果相邻，解释靠近证据，图片或视频比较连续排列。适用时把关键数量放进短标题。
- 看图形成的直觉旁边放对应图片，表格每格保持简短。依赖长段解码的图重新设计，图注补充必要背景。
- 公式排版：离线 HTML 用原生 MathML，LaTeX 正常编译。

## 六、安全修改

冷读渲染结果。现场修改时，按用户指定段落改动、刷新并检查。实质修改前保留上一版，替换带上下文的完整字符串，逐项比对数字并确认图片身份。

交付文件、线上副本与压缩包按任务范围和授权同步，过程文件单独放入工作目录。

## 七、交付

离线 HTML 优先内嵌 SVG 图、JPEG data URL 与 MathML；保持用户要求的画质，体积或媒体需要时采用多文件包。报告与完整结果页打包时使用离线可跳转的相对链接。LaTeX 编译为所需产物并检查渲染。

交付具体文件位置。日志、核验、来源与修改说明放入独立记录；打开或发布沿用用户任务授权。

## 八、发出前自检

- [ ] 开头回答研究问题、答案、证据与下一步。
- [ ] 作者自己的思考有位置，公式已排版。
- [ ] 例子有适用分母，因果表达符合证据。
- [ ] 比较、存疑样本与 CPU/GPU 统计采用明确的科学定义。
- [ ] 发现与相关负结果保留，执行细节单独保存。
- [ ] 标题具体，语言表达实质研究内容。
- [ ] 颜色统一，应比较的对象相邻。
- [ ] 数字对应原始证据，每张图身份明确。
- [ ] 渲染与离线链接可用，约定副本已同步。

## 可选 HTML 工具

[templates/report_helpers.py](../templates/report_helpers.py) 只使用 Python 标准库，提供内嵌 SVG 条形图、折线图、时间轴、阶段块、JPEG 嵌入与 MathML 示例。在临时输出目录运行生成 `report.html`，以研究证据替换标明为演示的数据。按论证选择所需函数与布局。
