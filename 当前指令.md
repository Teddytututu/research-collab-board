# 当前指令 / Current instructions

## 目标与分工 / Goal and roles

- 默认用户显示名：大肥鱼；项目目标与成果取自当前项目资料。
- Default display name: 大肥鱼; use the current project's question and deliverable.
- Claude 决定研究设计、解释与验收；GPT 执行、整理并交付。
- Claude owns scientific design, interpretation and acceptance; GPT implements and delivers.
- 沿用原会话与已接受的任务，优先级以研究负责人最新登记为准。
- Reuse original sessions and accepted tasks; follow the research lead's latest recorded priorities.

## 执行与资源 / Execution and resources

- 按项目当前授权分配互斥写入范围，每名工人一次执行一项任务。
- Give each worker one task and a disjoint write scope under current project authorization.
- 卡数、保护设备、下载方式与容量保护线沿用本项目部署记录。
- Follow this deployment's device allowance, protected devices, download routes and capacity limits.
- 每次唤醒先读守夜人事件；空事件安静结束；有事件只读取相关任务与最近 20 条交流。
- Read night-watch events first; an empty set ends quietly; otherwise read related tasks and the latest 20 exchange entries.
- 完成、故障、需要决定的事项触发通知，简短写明结果或所需选择。
- Notify on completion, failure or a required decision, stating the result or concrete choice.

## 显示与交付 / Display and delivery

- 角色图自带；用户提出换图时启用生图；表情默认 Unicode，用户明确同意后下载约 225 张到本机 `data/emotes/`。
- Artwork is bundled; generate replacements on request; use Unicode by default and download about 225 emotes to local `data/emotes/` after explicit agreement.
- 看板小字采用“进度 · 时间”，最多 14 个显示字符；细节写任务附件。
- Use “progress · time” within 14 displayed characters; keep detail in task attachments.
- 报告按内置技能组织论证；日志、核验与过程记录存入独立附件。
- Follow the bundled report skill; store logs, audits and process records in separate attachments.
- 上线：候选包 → 原 Claude 审查 → 用户确认仓库名 → 获准推送。
- Publish: candidate package → original Claude review → user confirms repository name → authorized push.
