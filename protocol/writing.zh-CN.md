# 看板与协作消息写法

[English](writing.md)

适用于进度小字、任务状态、给用户的讨论消息与助手交流板。用户称呼取项目设置，新项目默认“大肥鱼”。

## 进度小字

一格写一个任务的当前阶段，格式为**进度 · 时间**，或一个状态词。整格最多 **14 个显示字符**，空格与标点计入。先压缩措辞，预计时间放入后超长时保留完成数。

| 情况 | 写法 |
| --- | --- |
| 正在跑，当天完成 | `12/60 · 约06:14` |
| 正在跑，跨到次日早晨 | `12/60·明早06:14` |
| 暂停 | `196/320 · 暂停` |
| 已停 | `196/320 · 已停` |
| 生成结束，正在收图 | `收图797/1000` |
| 等具体动作 | `等你登录` / `等审核` / `等空卡` |
| 估时依据待补充 | `12/60` / `—` |
| 文档或界面交付 | `约23:00交` |
| 已交付，等待审阅 | `已交` |

表内示例适用于中文界面，其他语言采用同样简短的本地表达。阶段完成后写当前阶段；完成日期晚于今天时标明次日。原因、文件名和详细计数放入点击“+”展开的任务文件。一格数字只对应本任务。

## 给用户的消息

**一两句说完**：先写结果或用户要做的具体事情，再给一个关键数字。采用日常用语与肯定句。任务编号、校验值、进程细节与实现记录放入附件，用户问题涉及这些内容时按需提供。

示例：“60 组对照完成了，报告按同一批样本展示三种方法。”

## 助手交流板

每条最多**三句**：完成了什么、关键数字、下一步或交给 Claude 的决定。研究选择直接在交流板提出，给出两个具体选项与建议。支撑材料只提供一个入口路径。

## 读者材料

围绕读者的问题组织发现，日志、检查和来源记录放入独立附件。研究报告和结果页采用[研究报告技能](../skills/research-report-writing/SKILL.md)。

发送前核对：这一行能说明目前到哪、适用时预计几点完成，以及适用时用户要做的具体动作。
